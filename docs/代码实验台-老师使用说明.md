# 代码实验台：老师使用说明

版本 **1.0.0 · Windows x64**。适用于基础语法到算法入门的小班演示；C++11/14 单文件程序。

## 上课前

1. 将发布包完整解压到可写文件夹，中文路径可用；不要在压缩包里直接运行。保留 `runtime` 的完整结构。
2. 双击 `start.bat`，检查通过后自动打开浏览器；地址会显示在启动窗口，通常是 `http://127.0.0.1:8765/`。启动窗口须保持开启。
3. 以后直接使用本项目启动入口；提示未连接时，先双击 `start.bat`，再点“重新连接”。
4. 选“数组求和”，点击“开始”→“下一步”，确认变量区出现，再开始投影。已保存的 JSON 用“载入课例”打开。

## 课堂操作

| 操作 | 用法 |
|---|---|
| 开始 | 编译并停到第一处，标准输入须提前填好 |
| 下一步 / 跳过函数 | 执行一行，函数调用一次执行完 |
| 进入函数 | 观察函数内部与递归；调用栈可查看各层 |
| 播放 / 暂停 | 连续推进 / 暂停；速度可调 |
| 历史条 | 回看已执行结果；继续执行时先回到最新 |
| 停止 / 重新运行 | 结束本题 / 从头再跑；死循环时优先点停止 |
| 保存课例 | 下载代码、输入、展示设置；不保存执行历史 |

代码、变量、数组与容器、输入输出同时显示；拖动分隔线调整比例，双击恢复默认。变量与“数组与容器”之间也可上下拖动，键盘聚焦分隔线后用上下方向键微调，按住 Shift 加大调整幅度；区域高度随课例保存，也可刷新恢复。默认代码占宽度 45%，输入输出占右侧高度约四分之一；调整后的比例保存在本机。进入函数、重新运行、课例管理和标准设置在“更多”中。

变量按“变量名｜值”紧凑排列；局部和全局分栏，共用一层纵向滚动。状态旁的 ⓘ 可悬停查看说明。数组和容器只显示数量摘要，点击“查看”会定位到对应数组。调用栈在变量标题右侧展开。

运行状态与下一条行号紧随顶部运行操作；播放和暂停共用一个按钮位置，随运行状态切换。输入须在开始前一次性填好，暂停时不追加输入。底部“执行历史”显示实际执行步数；回看时标明“正在回看历史”，点击“返回最新”回到当前运行现场。

各区域用标题旁的颜色标记区分：代码蓝、变量紫、数组青、输入琥珀、输出绿。黄色箭头表示下一条待执行代码，橙色表示本步变化，青色轮廓与指针表示老师关联的下标位置；下标指示不代表已经确认发生了读写。

一维数组始终为一条，较长时在数组内部横向滚动；二维数组按真实行列排列。切换窗口会标明未读取与省略部分。普通刷新保留滚动位置；单步确认读写位置时自动定位到相关格子，源与目标距离过远时优先显示写入目标。

单步执行后，蓝色格子表示本步读取，橙色格子表示本步写入，即使写入前后数值相同也会标出。比如 `a[i+1] = a[i] + (s[i]=='1');` 会标出 `a[i]`、`s[i]` 与目标 `a[i+1]`；不显示额外计算过程。标记随历史回看还原。含函数调用、条件路径或副作用等无法可靠确认的语句不推测读写。

一维数组和 vector 在当前读取窗口中出现连续相同的已知值时，用叠片 `⋯` 格子折叠中间部分，点击展开，再次点击收起；悬停查看范围、数量和值。正在读写、变化或关联下标的格子保持展开；未知值和窗口外未读取的值不会作为重复值折叠。字符串默认大字显示字符，可切换“字符 / 编码”，UTF-8 字节说明收在信息图标中。

已确认数值为 0 的数组格子用灰色弱化，仍然是有效的数值；本步发生变化时优先显示橙色，下标轮廓也会保留。数组卡片“范围 → 展示前”可设置 1–200 个元素，从下标 0 开始展示，超出的数量明确标为隐藏；这项操作不执行代码。应用后的前缀设置可随课例保存，并在重新运行、载入课例后恢复。

“更多 → 代码配色”可选 VS Code Light+、VS Code Dark+、Dracula；默认浅色，编辑与执行视图均按 C++ 语法着色。代码主题只影响代码区域，保存在本机，也随课例保存。注释、字符串、数字和关键字分别着色，未完成的代码仍可正常编辑。

“更多 → 动效”可选标准、减少、关闭，偏好保存在本机。标准模式尊重系统减少动态效果设置；快播放简化动效，历史回看立即显示选中状态。运行结束的勾选仅表示程序正常结束。

输入高亮本步读取的字符，输出高亮本步新增字符；历史回看同步还原。读取位置无法确认时不标记。数组与容器默认展开，“范围”中可调整读取范围。

**高亮行是下一条待执行语句**，变量是已执行的结果。未初始化或不能确认的值会屏蔽：灰色“待确认”表示暂时无法证明数值有效，红色“未赋值”表示已确认声明后尚未初始化，教学时应提醒在声明时初始化变量。首次获得确定值也使用橙色变化高亮，旁边显示“待确认 → 数值”或“未赋值 → 数值”；下一步未再变化就恢复普通样式。历史回看保留该步高亮，但不重复播放动画。单行标准 `cin` 输入成功后显示真实数值，复制该数值的变量也会正常显示；输入失败或不足时仍会保留未确认提示。数组默认显示 50 格，大数组按窗口读取；下标关联由老师选择。

## 下课

先保存课例，关闭实验台标签页，再双击 `stop.bat`，或在启动窗口按 **Ctrl+C**。窗口提示“已停止”后，所属 GCC/GDB、学生程序和临时文件均已清理。关标签页只关闭当前调试会话，服务可继续给下一节课使用。强制关闭窗口由 Windows 回收所属进程；来不及删除的本次临时目录在下次启动回收。

## 安装与离线

完整发布包附带 Python **3.14.3**、GCC **15.2.0 Rev13**、GDB **17.1**，以及 pygdbmi **0.11.0.0**、tree-sitter **0.25.2**、tree-sitter-cpp **0.23.4**。已有课例编译、单步和播放均不需要联网，也不需要 Node.js。

源码版优先使用 `runtime/python`、项目 `.venv`，最后使用系统 Python；`start.bat --check` 可只检查环境。首次配置缺依赖时会显示当前 Python 对应的完整安装命令。Python 包版本锁在 `requirements.txt`，本包 `wheelhouse` 仅适配 Windows x64 / Python 3.14。

源码版首次安装（PowerShell，位于代码实验台目录）：

```powershell
python -m venv .venv
& .venv/Scripts/python.exe -m pip install -r requirements.txt
```

已备好 wheelhouse 时，将最后一行换为 `& .venv/Scripts/python.exe -m pip install --no-index --find-links wheelhouse -r requirements.txt`。缺编译器时，在 MSYS2 UCRT64 终端运行 `pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-gdb`；固定验证组合以上述发布包为准。

## 已知限制与回退

- 仅在本机回环地址服务；一次最多 8 个调试页。只运行老师信任的课堂代码，工具不是隔离沙箱。
- 预先提供输入；最多 2000 条快照、1 MB 输出，连续执行默认限时 30 秒。
- 后台标签页的心跳可能被浏览器暂停；超过 60 秒没有心跳的会话会回收，回到页面后重新运行即可。
- map、set、链表、树尚未提供专门展示；复杂指针与初始化状态可能显示“状态未确认”。
- 实验台异常时先保存课例、停止服务，回到 Dev-C++ 继续演示。升级前保留旧版文件夹与课例，需回退时停止新版、启动旧版；JSON 课例版本目前为 1。

详细处理见 [故障处理](代码实验台-故障处理.md)。源码维护者可用项目 Python 执行 `build_release.py` 生成新目录，验收后执行 `build_release.py --zip-only` 打包；`manifest.json` 记录版本及逐文件 SHA-256，ZIP 旁另有校验文件。第三方许可保留在 `runtime/python/LICENSE.txt`、Python 包元数据目录、`runtime/ucrt64/share/licenses` 和工具链原有许可文件中。
