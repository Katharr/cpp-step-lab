## 已确认的基点失败

对照基点：`07c5974bc0b27e272fffcde16d11327caa198463`。从该提交提取项目源码至本项目内的临时目录，用同一工具链复跑确认以下问题同样存在；对照临时目录已清理。未修改这些断言以掩盖失败，也不将全套检查表述为全部通过。

| 入口 | 失败内容与基点证据 |
| --- | --- |
| `test_general_function_arguments_and_expression_contexts` | 旧断言期待空 writes，但真实引用函数调用报告了 `a[1]` 写入；基点复跑同样失败。 |
| `test_uninitialized_arrays_never_expose_stack_values` | 未初始化数组被报告为 `ok`，与旧断言不符；基点复跑同样失败。后续确认是整体结构与元素状态混淆导致的旧断言，元素实际均被正确屏蔽。 |
| `appearance-check.cjs` 的真实变量状态用例 | 旧断言期待 n 为“待确认”，实际为“未赋值”。基点源码运行相同 C++ 程序到第 6 行，也报告 n 为 `uninitialized/null`。 |
