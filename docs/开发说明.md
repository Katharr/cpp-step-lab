# 开发说明

本项目面向 Windows x64 上的 C++11/14 单文件教学程序，使用真实 GCC/GDB 执行。安装与日常操作见[根目录 README](../README.md)，课堂操作见[老师使用说明](代码实验台-老师使用说明.md)。本文说明当前实现与维护入口。

## 环境与目录

Python 开发环境统一为项目根目录 `.venv`，依赖由 `requirements.txt` 锁定；网页测试依赖由 `package.json` 和 `package-lock.json` 锁定。网页没有构建步骤，课堂运行无需 Node.js。所有资源从本项目读取，脚本以自身位置解析路径。

| 文件或目录 | 当前职责 |
| --- | --- |
| `start.bat`、`stop.bat`、`launch.ps1`、`launch.py` | 保持根目录用户入口；仅统一引导包路径。 |
| `src/code_lab/bootstrap.py`、`paths.py`、`config.py` | 生命周期、项目资源定位与公共运行限额。 |
| `src/code_lab/server/` | HTTP、静态资源白名单与页面会话管理。 |
| `src/code_lab/execution/` | 工具链、编译、普通运行与进程清理。 |
| `src/code_lab/debugger/` | 调试会话、MI 通道、I/O 观测；`gdb_agent/` 在 GDB Python 独立执行。 |
| `src/code_lab/snapshots/` | 语法事实、初始化证据、变量身份、格子访问与快照差异。 |
| `web/core/`、`web/features/` | 统一状态、API，以及按教学功能划分的原生 ES modules。 |
| `web/presentation/`、`web/styles/` | 布局、主题、动效与公共样式；功能专属样式随功能维护。 |
| `课例/` | 由 `index.json` 索引的 JSON 教学课例，网页不另存一份代码。 |
| `contracts/` | 快照、课例的数据格式与样例。 |
| `tests/fixtures/cpp/` | 真实 GCC/GDB 和网页验收共用的 C++ 回归样例。 |
| `tests/`、`scripts/release/` | 各级验收与发布入口。 |
| `docs/` | 当前使用说明、架构、接口、故障处理与效果图。 |

模块依赖和扩展规则见[架构说明](architecture.md)，接口与数据约定见[API 说明](api.md)。

工具链优先使用 `runtime/ucrt64`，其次检查 `C:/msys64/ucrt64` 和 PATH。GDB 需要内置 Python；源码开发使用根目录 `.venv`，便携包携带完整 `runtime`。中文项目路径通过 ASCII 临时编译目录和工具链路径适配处理，不把本机工作区路径写入代码或文档。

## 执行与接口

调用链为：网页 → 本机 HTTP 服务 → `DebugSession` → GCC/GDB → 结构化快照 → 网页。服务只监听 `127.0.0.1`，不提供远程执行，也不隔离用户 C++ 程序的系统权限。

HTTP 字段与快照格式见 [API 说明](api.md)。每个页面独立持有会话，每次运行使用新的身份；执行与窗口观测在同一会话内串行，停止可先设置取消标记，打断正在等待的 GDB 命令。运行限额以 `src/code_lab/config.py` 为准。

调试会话使用 `with` 或显式 `close()` 回收进程和工作目录；课堂暂停不计入连续执行时限。

## 快照与展示约定

- `line` 是下一条待执行语句，变量值是暂停时已经形成的状态；不能把两者误标为同一步动作。
- 代码区始终使用同一 textarea 与语法叠层；编辑权限由真实运行状态、请求状态与历史位置决定。编译、运行、暂停、历史回看及执行结果未知时只读，仍允许选择与复制。课例载入入口使用同一锁定规则，文件异步读取期间也锁定开始与编辑。
- 主高亮消费 `execution.spans` 中本执行步已确认完成的源码范围；下一条箭头来自暂停位置 `line`。循环头显示原源码，内部按真实检查点区分初始化、条件和更新；调用结果在实际返回后才确认。没有执行证据时不将行号差当作完整语句完成的证明。
- 正常结束、异常中断和人工停止保留相应时刻的最后可信观测；终止状态清除下一条箭头。终态数据是否来自当前暂停点或先前观测，由 `execution.stateOrigin` 区分。
- `frames` 使用稳定调用实例身份；变量身份同时包含运行、调用实例、声明与作用域，不能只按变量名匹配。递归、遮蔽和全局变量须分别处理。
- `state` 区分 `ok`、`uninitialized`、`unavailable`、`out_of_scope`。无法证明初始化、读取失败或作用域外的 `value` 为 `null`，不展示栈槽垃圾值。确认标准 `cin` 输入时以真实流状态为依据，不额外调用用户程序的方法。
- 数值以字符串传输，64 位整数不经过 JavaScript 浮点转换。`changed` 表示可靠前后值不同，`previousValue` 保留前值；值状态变化单独处理。
- `data` 包含 `kind/shape/lowerBounds/total/offset/limit/hidden/state/note/elements`；元素包含 `index/coordinates/value/state` 及差异信息。展示层使用结构化字段，不解析 GDB 输出文本。
- 数组默认读取 50 个元素，单窗口限制为 1–200。只读取窗口内元素；切换窗口不执行代码、不新增历史，且保留当前步 I/O 增量与差异基线。`vector<bool>`、不兼容的容器布局和三维以上数组应显示限制说明。
- `arrayAccess` 包含来源 `line`、`reads` 和 `writes`，有函数实参使用时增加 `uses`；条目以 `variableId` 和 `coordinates` 定位。用执行前状态确定下标，执行后显示蓝色读取、橙色写入、紫色函数实参使用；写入相同数值也标记。三元表达式保留条件中必然发生的读取，以及两个分支都会访问的同一格子；嵌套分支递归取交集，同一格子去重。仅单侧分支、短路右侧等未确认路径不猜测。
- 格子访问按表达式节点递归识别，不因含有函数调用而屏蔽整条语句，也不维护普通函数名称白名单。裸元素作实参统一记录 `uses`，避免将传引用冒充读取；实参中的算术运算仍记录 `reads`。支持多参数、嵌套调用及多行语句；进入函数时只记录已完成求值的该次实参，不提前标记外层赋值。调用点只确认实参使用，不能据此推断函数体读写；若本执行步实际经过函数体检查点，则合并这些检查点已确认的访问，包括引用参数对数组元素的同值写入。副作用下标、可能被其他调用改动的全局或逃逸下标不猜测，不向 GDB 求值用户表达式。
- 标准输出中的数组取值也属于读取。直接标准 `printf` 的常量普通格式串可确认 `reads`；动态格式、同名用户函数、`%n` 等不能证明读取方向时仍按通用实参规则记录 `uses`。多行语句仅在离开完整语句后标记，中途暂停不标记；不依赖 stdout 缓冲或刷新时机。
- `output` 保存累计输出，`outputDelta` 保存本步新增输出，`inputTrace` 保存可确认的输入消费位置。UTF-8 字节位置转换为可展示的文本范围；位置未知时不给出猜测高亮。
- 历史使用独立快照，代码、变量、读写标记和 I/O 一起还原。回看不倒退真实程序；继续执行先回到最新状态。历史回看不重复执行动画。
- 重复值折叠只作用于当前窗口中已读取且可靠的连续相同值。读写、函数实参、变化和关联下标位置必须露出；未知与未读取部分不能折叠成确定值。函数实参也参与离窗定位与历史还原。
- 课例 JSON 的 `version` 当前为 1，保存 `code/input/display` 和展示设置，不保存执行历史或临时进程信息。
- 变量竖栏与代码通高，数组与 I/O 在右列；`display.layout` 保存 `codeWidth/stateHeight/variablesWidth/variableColumns`。旧字段 `variablesHeight` 忽略并使用默认栏宽，课例版本仍为 1。窄窗口只限制实际栏宽和可显示列数，不覆盖已保存的双列偏好。普通变量格子按快照顺序排列，数组摘要位于该分组末尾；以稳定变量身份关联历史、长值展开和数组下标。选中其他调用帧时，变量栏与数组同步切换。

初始化证明和读写识别面向教学中常见的可确认语句，不是通用 C++ 数据流分析。支持范围是单线程、未优化的课堂代码；未定义行为、复杂指针和任意库布局不保证可视化结果。

常用库函数返回值统一按参数与真实标准容器类型验证，规则集中在 `src/code_lab/snapshots/initialization.py` 的 `VALUE_CALLS`、`CONTAINER_QUERIES`；完整名称、重载范围及确认边界见[信奥常用函数支持](信奥常用函数支持.md)。

### 下标标记的维护落点

自动关联由 `snapshots/source_facts.py` 选择当前循环或语句中的直接下标，`snapshots/execution.py` 提供真实暂停位置，`snapshots/builder.py` 绑定稳定变量身份。同一行的多个循环按检查点位置区分。

`web/features/data/index-markers.js` 管理手动固定、明确取消、同格合并、提示与尺寸重排；`data.js` 消费相同的当前位置来保护重复值折叠并关联变量栏。重建数据视图前解除旧尺寸监听，重新展开或缩放后依据真实格子中心排布。

偏好持久化与身份恢复字段见 [API 说明](api.md#课例)，显示规则见[老师使用说明](代码实验台-老师使用说明.md#一维数组的多个下标)。

## 开发验收

先按根 README 准备 Python、GCC/GDB 和本项目依赖。在项目根目录运行：

```powershell
# 真实调试、结构、I/O 与 HTTP 回归
& ./.venv/Scripts/python.exe check.py

# 安装锁定的网页测试依赖
npm ci
```

用 `start.bat` 启动服务，再在另一个 PowerShell 窗口运行所需网页验收：

```powershell
npm run test:browser
npm run test:data
npm run test:layout
npm run test:appearance
npm run test:visual
```

`test:visual` 包含格子视觉及真实读写回归。默认使用本机 Edge，不下载浏览器；`CODE_LAB_BROWSER` 可指定 Chromium 浏览器的可执行文件，`CODE_LAB_URL` 可指定服务地址。网页通过本机 HTTP 服务加载 ES modules 与课例；请使用 start.bat 启动，不直接打开 HTML 文件。

按改动选择相关检查；修改调试、静态资源或发布路径时，必须执行相关真实 GCC/GDB 与网页验收。测试结束运行 `stop.bat`，确认本次服务、GDB、编译器、学生程序及临时目录均已清理，不按进程名称结束其他程序。历史通过记录不能代替本次验收。

网页截图和报告位于 `验收输出/`；命令行调试诊断位于 `.local/debugger/`。这些输出、`.local/`、虚拟环境、运行时、离线依赖和二进制发布包均不提交到 Git。日志和课例不存放学生、家长等真实身份信息。

## 发布维护

构建流程与命令见[发布说明](../发布/README.md)。发布资源从本项目清单读取，包含运行模块、网页、8 个课例、当前说明与截图；测试脚本保留在源码仓库，不进入便携包。清单和 ZIP 使用同一发布范围，目录中额外添加的本地文件不会随应用打包。`runtime/ucrt64` 和 `wheelhouse` 需要预先准备，不随 Git 克隆提供。

新版本发布前，在新目录验证中文路径、断网、服务启停、单步、数组、历史和课例载入。`scripts/release/verify.py` 验证发布包独立运行与清理，`npm run test:delivery` 验证断网网页流程。验收后生成 ZIP 与 SHA-256，不覆盖正在使用的发布目录。

Python 依赖沿用其上游许可证，运行时和工具链保留原有许可文件；新增第三方代码或依赖时记录来源、版本、用途及许可证。文档只在本项目维护。
