# 代码实验台术语

本术语表定义课堂单步演示中的执行与观测概念。

## 执行与观测

**暂停点**：程序暂停、可观察当时状态的位置；同一源码行可以对应多个不同暂停点。
_避免_：把源码行当作唯一暂停位置。

**执行步**：相邻两个暂停点之间发生的真实执行区间，可以包含多个动作；区间终点也可以是程序结束。
_避免_：将一步固定等同于一行代码或一条完整语句。

**数值变化**：同一对象在执行步两端的可比较、已确认数值不同。
_避免_：用数值变化指代所有写入或首次确认。

**访问归因**：将对象的读取、写入或实参使用关联到对应执行步的证据结论。
_避免_：把缺少归因视为没有访问。

**初始化证明**：能够确认对象已获得有效初始值的证据；读到一个数值本身不构成初始化证明。
_避免_：把可读取的栈槽数值直接当作已初始化的变量值。

**首次确认**：对象的值首次能够可靠展示的状态变化，不意味着存在可比较的旧值。
_避免_：把首次确认直接表述为数值修改。

**窗口观测**：在一个暂停点读取的数组或容器局部数据；没有采集的位置不具备该暂停点的历史数值。
_避免_：用当前值填补过去未记录的元素。
