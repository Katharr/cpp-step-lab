# 信奥赛常用函数与返回值显示

适用 C++11/14 与本项目 GCC。以下函数的返回值在观察到语句执行完成后，可以作为变量已初始化的证据；实际值始终来自真实 GDB，实验台不重算这些函数。`int len = max(len1, len2);` 在两个参数已确认时会正常显示 `len`。

## 支持的参数形式

| 形式 | 范围 |
| --- | --- |
| `min/max/minmax` | 双参数，或一个初始化列表；支持 `max<int>(a, b)` 等基本类型模板参数。 |
| `stoi/stol/stoll/stoul/stoull/stof/stod/stold` | 单参数。带输出位置指针的重载不作初始化证明。 |
| `accumulate/inner_product` | 分别为 3/4 参数，不接收自定义运算器。 |
| `lower_bound/upper_bound/binary_search/count/find` | 3 参数，不接收自定义比较器/谓词。 |
| `min_element/max_element/minmax_element/distance` | 2 参数。 |
| `equal/mismatch/lexicographical_compare` | 分别为 3/3/4 参数，不接收自定义比较器。 |
| `getchar/rand` | 无参数；`putchar/puts` 为单参数。只证明返回值，不用它们推断其他变量的初始化。 |
| 其他函数 | 按标准参数个数验证；实参逐个递归检查，支持嵌套调用和算术表达式。 |

此外支持基本类型的函数式转换（如 `int(sqrt(n))`）、基本类型 `static_cast`、C 风格转换、`sizeof`，以及 `std::numeric_limits<基本类型>` 的 `min/max/lowest/epsilon/round_error/infinity/quiet_NaN/signaling_NaN/denorm_min` 无参数查询。

## 确认边界

- 参数必须已有初始化证据。未知参数、`x++`、自定义回调、未知函数嵌套调用不被当成确定来源；同名用户函数、宏、局部可调用对象也不套用标准函数规则。
- 标准容器声明执行完成后才能查询；`std::array` 的默认声明不初始化元素，继续保留未初始化状态。
- “下一步”和“进入函数”都支持：进入库函数期间不提前显示调用结果；返回调用者且语句完成后再确认。历史快照保持原来的值。`finish`/连续运行仍按现有规则清除未逐步观察到的局部初始化证据。
- `sort/reverse/swap/fill/memset/memcpy`、容器 `push/pop/insert/erase` 等修改操作不能仅凭名称证明所有目标已赋值；其中返回 `void` 的函数也不能初始化普通数值变量。输入目标仍由现有标准流观测规则确认，不能把 `scanf` 的返回值等同于所有目标已写入。
- 自定义函数需要单独的函数体数据流证据；当前不会把任意返回值都标为可靠。指针解引用、不合法下标、无效迭代器、越界、除零和其他 C++ 未定义行为不在保证范围。
- `std::gcd/std::lcm/clamp` 是 C++17 功能，不属于本项目 C++11/14 环境；公约数可用该环境的 `std::__gcd`。
