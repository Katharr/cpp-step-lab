# 本地课例

网页端“保存课例”会下载一个 JSON 文件，并在浏览器本机记住最近课例。此目录用于老师整理下载后的课例；课例只保存代码、输入、展示设置和版本信息，不写入临时调试进程或运行历史。

1.0.0 附带下列可直接用“载入课例”打开的 JSON（均为课例版本 1）：

| 文件 | 适用层次与用途 |
|---|---|
| swap.json | 入门：赋值与变量交换，附带 64 位整数精度演示 |
| array.json | 入门：基础语法收尾，数组输入与求和 |
| matrix.json | 入门：基础语法收尾，二维数组与双重循环 |
| adjacent.json | 入门：基础语法收尾，相邻元素交换与下标范围 |
| function.json | 提高：函数参数与局部、全局变量 |
| recursive.json | 提高：递归调用与各层独立数组 |
| prefix.json | 提高：算法入门，前缀和数组 |
| containers.json | 提高：vector 追加与 string 修改 |

这些是教学演示片段，按代码和输入直接运行；不是完整 OJ 题面。网页通过本机服务读取 `index.json` 和这些 JSON 文件，内置课例内容只在此处维护。增加课例时同时更新索引中的 `id`、`title`、`file`，文件名使用与 `id` 一致的英文名称。
